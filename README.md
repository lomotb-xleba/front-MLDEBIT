# ml-debit-ui

Интерфейс проекта на React + Vite + TypeScript.

## Требования

- Node.js 18+ (рекомендуется 20+)
- npm 9+

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

После запуска откройте адрес, который покажет Vite в терминале (обычно `http://localhost:5173`).

## Сборка проекта

```bash
npm run build
```

## Предпросмотр production-сборки

```bash
npm run preview
```
